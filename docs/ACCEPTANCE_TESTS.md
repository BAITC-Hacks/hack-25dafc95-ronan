## Минимальное демо

Свободный запрос → карточка → предложение количества → демонстрация неизменной корзины → подтверждение → переход в корзину. Затем zero-stock аналог, утверждённая политика, отсутствующий сертификат и конфликт 160/250.

Набор должен содержать разные формулировки запросов, а не единственный жёстко прописанный сценарий. Синтетические проверки и реальные smoke tests показываются отдельно.
