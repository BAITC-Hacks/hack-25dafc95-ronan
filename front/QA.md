# Фактически выполненные проверки

Дата: 23 сентября 2026. Windows, Node 24.17, Chrome через Playwright. Проверялась статическая production-сборка Vite, а не только dev-режим.

| Проверка | Результат |
| --- | --- |
| `npm run build` | Успех: строгая TypeScript-проверка и статическая сборка |
| `npm test` | 10 из 10 прошли, Vitest 4.1.11 |
| `E2E_EXTERNAL=1 npm run test:e2e` с запущенными preview-серверами | 9 из 9 прошли; exit code 0; 26,6 с |
| npm audit при последней установке зависимостей | 0 известных уязвимостей |
| Визуальный осмотр PNG desktop и mobile | Выполнен; снимки в `qa/` |

## Пять must-have

1. DEMO-1001: наличие 120 м на выбранном складе, параметры, ссылка на тестовый документ и HTTP 200 проверены браузерным тестом.
2. Отсутствующая исходная позиция и аналог: причина, совпадения и предупреждение о необходимости проверки совместимости присутствуют.
3. Подготовленный ответ об оплате, доставке и минимальной партии проверен.
4. Предложение и отмена не меняют корзину; двойной клик не дублирует добавление; превышение остатка учитывает уже добавленное количество. Изменение и удаление требуют своего согласия.
5. Прямая ссылка ведёт на `/#/cart`; после обновления страницы сохраняются позиция, количество и итог.

## Остальные браузерные сценарии

- Desktop 1440 px, мобильная панель 390×844 и уменьшенная высота 390×480.
- Отдельная мобильная корзина, Escape, возврат фокуса, Tab, отсутствие горизонтального переполнения.
- Enter / Shift+Enter и синтетическое событие клавиатуры с `isComposing=true`.
- Вложения: неверное расширение, PDF, удаление, превышение 10 МБ, честное сообщение о неподключённой обработке.
- Неизвестный запрос и повтор искусственной ошибки без дублирования сообщения пользователя.
- API без адаптера: ошибка, отсутствие демокарточек.
- Тестовый сетевой адаптер: реальное прерывание запроса браузера через Playwright `route.abort`, успешный повтор без демоподмены.
- Неоднозначный сбой изменения: ровно один commit; сверка `unknown` блокирует дальнейшие изменения, следующая сверка `applied` обновляет корзину.
- Изменившаяся цена: первая попытка не меняет корзину, новая цена показывается до второго согласия; после успеха используется возвращённая сервисом корзина.
- На стартовой странице не возникло JS-ошибок `pageerror`.

Тестовый стенд находится в `e2e/harness.*`. Его фиктивные запросы `/__test__/...` перехватываются исключительно тестами. Серверных маршрутов или backend для них нет; в production `dist` стенд не включён.

## Обнаружено и исправлено

- После закрытия мобильного чата фокус терялся: перенос фокуса теперь выполняется после отрисовки кнопки открытия.
- Фоновая страница прокручивалась под панелью: на mobile фон становится inert, прокрутка body блокируется.
- Уточнена семантика согласия: «да, добавь» не подтверждает удаление или изменение количества.
- Новая асинхронная котировка блокирует предыдущее активное предложение до завершения.
- Обновлён Vitest до версии без обнаруженных npm audit уязвимостей.

## Ограничения проверки

Реального API, реальных документов и публичного адреса нет. Не проверялись авторизация, доступность сервисов команды, реальные остатки, реальное встраивание в ekt.kz, физические телефоны, нативная экранная клавиатура, экранные дикторы и все браузерные движки. Изменение высоты viewport и IME проверены программно в Chrome, что не заменяет испытание на устройствах.

В sandbox стандартная загрузка Vite-конфига и dev-оптимизация esbuild сталкивались с запретом чтения родительского каталога Windows. Для сборки используется `--configLoader native`; статический `preview` работает. Автоматическое завершение Playwright webServer в этом sandbox зависало, поэтому финальный успешный прогон выполнен с внешними preview-процессами (`E2E_EXTERNAL=1`). Это ограничение окружения отражено в README.

Для публичной проверки осталось загрузить `dist` на выбранный хостинг и повторить основной путь по выданному HTTPS-адресу. Публикация не выполнялась.
